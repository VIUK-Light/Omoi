# Relation Diagram

Web ページに関係図を表示する、Omoi v3 から独立した汎用コンポーネントです。入力したノード・関係・注記を表示し、描画内容の更新と破棄を扱います。回答の収集、投票、人物の評価を行うコンポーネントではありません。

## デモと使い方

リポジトリのルートから実行します。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

[汎用デモを開く](http://127.0.0.1:4173/packages/relation-diagram/demo/index.html)。Omoi の画面は [v3 プレビュー](../../preview/omoi-v3/README.md) で確認できます。

デモでは、読書会の人物相関（`network`）、展示会の準備（`branches`）、原稿の受け渡し（`path`）、編集者を中心にした関係（`branches`の`direction: 'right'`）へ同じAPIで切り替えます。右向きの配置は中心を左、二人の相手を右上下に置き、スマホでも左右二列を保ちます。中心を薄い背景色で示し、辺ラベルを線の外側へ離すことで、連続した線を追えるようにしています。`path`は横幅が足りなければ縦に並び替えます。いずれもOmoiの質問・Level・URL条件に依存しません。

「二つのやりとり」は `pairs` 配置の例です。二人を一組として横並びにし、独立した組を行ごとに表示します。人物と短い動作だけを示し、元の説明文の分岐図とは区別します。スマホでも左右を保ち、文字を縮小しません。

`sequence.mjs` は、複数の関係図を〈／〉で一つずつ読むための部品です。場面の順序を追う表示と、並列のケースを比較する表示を分けられます。各場面の図は既存APIで更新し、質問IDや会話内容には依存しません。

エントリーポイントは `index.mjs` です。正確なデータ形式、取り込み方、更新・破棄、エラー時の扱いは [API.md](API.md) を参照してください。描画ライブラリ Cytoscape.js 3.34.4 は `vendor/` に固定し、第三者の MIT ライセンスを保持します。
