## 分析の基準

Omoiの目的は、普段は聞かなかった相手の考えと理由を知ること。重い話・深い問いへの特化も維持する。追加の価値は、カテゴリーの数や話題の新しさだけで決めず、次を確かめる。

1. 既存問と比べ、違う感覚・経験・価値観・迷いを聞けるか。
2. 具体的な場面と立場から答え、理由を話せるか。制度の賛否や望ましい行動の確認だけになっていないか。
3. 深い問いへの入口が薄い分野か。同じ葛藤を登場人物だけ変えて増やしていないか。
4. 事実と架空の条件を分けられるか。資料の対象・時点・不確実性を保てるか。

優先度は編集上の判断であり、利用者への調査や実際の会話による効果測定ではない。ネット資料は現実の論点を確かめる根拠として使い、特定の答えや追加の必要性を証明するものとして扱わない。

## 照合結果と限界

[照合記録](validation-report.json)に、942問の件数・ハッシュ、4,710問の配分合計、28案のID・参照先・CSV一致、文書リンクの確認を保存した。今回の分析中は問題正本の4ファイルを変更していない。

正規化後の完全一致は28案同士・既存942問との間で見つからなかった。意味の近さは分野担当と独立レビューで比較したが、3,768問を供給できることや全ての意味の非重複を証明したものではない。資料の確認範囲も個別に記録し、家事の段取りの論文は公開概要の確認に限る。
