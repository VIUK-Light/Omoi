## Levelと重さの配分

| Level | 現在 | 追加案 | 目標案 | 役割 |
| --- | ---: | ---: | ---: | --- |
| L1 | 175 | +525 | 700 | 身近な好み・経験の入口 |
| L2 | 98 | +702 | 800 | 日常・集団・境界を通じて深い話へ入る橋渡し |
| L3 | 307 | +1053 | 1360 | 制度・社会・役割についての判断 |
| L4 | 362 | +1488 | 1850 | 自分の利害・価値観・迷いへ置き換える深い問い |

L3・L4は合計3,210問（68.2%）。重い話・深い問いを中心に保ち、L2は98問から800問（17.0%）へ厚くする。自己犠牲か善行かだけで重さを作らず、喪失、人生の意味、所属、記憶、希望、信頼などの深さも増やす。

独立レビューで合計・現行件数を下回らないこと・視点比率を照合した。数字を変更すべき必須の根拠は見つからなかったが、これは各分野で目標数を供給できると検証した意味ではない。

| 拡充時に重なりやすい軸 | 別の問いと数えるために保つ差分 |
| --- | --- |
| 家族のケアを受ける自律／健康の配慮を受ける感覚 | 任せたいこと・自分で決めたいことと、治療・体調・配慮に固有の判断を分ける。同じ支援の場面を分類だけ変えて重複計上しない。 |
| 家族の悲嘆／技術の故人記録／文化・歴史の家族の記憶 | 喪失の受け止め、アクセスや共有の責任、公共の歴史として語る意味をそれぞれ中心に置く。写真・日記・メッセージという媒体の違いだけでは別問と数えない。 |
| 倫理の責任・許し／関係や司法の責任・許し | 具体的な分野の主語を外しただけでは追加価値と数えない。その分野を越えた判断基準そのものが主題かを比較する。 |
| 住まいの見守り／家族や恋人による監視・支援 | 自宅への継続的な訪問、住居を確保する本人の選択を残す。既存 `privacy-001`・`children-010`・`relationship-117`・`elderly-010` の人物名だけを置き換えない。 |

## 量を増やすときの扱い

| 工程 | 今回準備するもの／次の具体的な成果物 |
| --- | --- |
| 不足の分析 | 現行件数、近い既存IDと原文、独立した不足軸、資料を確認した代表候補。資料の確認範囲と限界も個別に記録。 |
| 細かな論点への展開 | 分野別の拡張軸をtopicに分け、まだ聞けない感覚・経験・価値観・判断を特定する。場面・人物名・サービス名の置換だけは新問と数えない。 |
| 3,768問の本文作成 | この数量表に沿った未承認の候補を別ファイルへ準備。個々に既存との差分、Level・分類、必要な背景・事実の根拠をそろえる。現段階では未作成。 |
| 重複と思想のレビュー | 語句の重複に加え、背景が同じ価値判断に収束していないか、相手の理由を聞けるか、L4を自分に置けるかを分担して確認。資料数やAIの賛成人数で採用しない。 |
| 最終確認と反映 | 確認できる候補一覧・差分・検証を先に完成させ、ユーザーの明示指示どおり、正本へ反映する前に問題の最終確認を取る。 |

この表の承認と、個々の問い・背景の承認は別。問題の変更を最後に確認するというユーザー指示を、量の目標への回答で取り消したとは扱わない。カテゴリーは現在の18分類を使い、今回の数量分析だけで新しい分類や画面の抽選規則を導入しない。
