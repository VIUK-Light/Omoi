## 機能の仕様（確定事項）

| 項目 | 内容 |
|---|---|
| 対象モード | 「すべてから選ぶ」「自分で選ぶ」のみに「対話モード」チェックボックス。学生モードは対象外 |
| 開始 | チェックして開始 → 本流のJSが選ばれた問いを `POST /api/rooms` でルームに投入 → ホストは `https://omoi-live.../host/<code>?k=<hostKey>` へ遷移 |
| 参加 | ホストのQRコードかリンクで参加者は `/r/<code>` へ。ニックネーム(1〜20文字)だけで入室、アカウント不要 |
| 回答 | 各自のスマホで自由記述(≤1000文字)。送信後も「編集する」で書き直せる |
| 公開 | **全員が書き終えたら自動公開**。ただし**参加者2人以上のときだけ**（ホストが1人で先に書いてQRを配る流れを守るため）。ホストは「全員分を公開する」で強制公開も可能 |
| 進行 | ロビー → ホスト「はじめる」 → 各問い(書く→一斉公開→会話) → ホスト「次の問いへ」/ 最後は「対話を終える」 |
| 揮発性 | 回答はRoomDOのstorageにのみ存在。ホスト終了時 or **3時間無操作**で storage 全削除 + 接続切断。送信ログにも残さない |
| 上限 | 問いは最大100問（超過分は静かに切れる ← 改善候補） |

## アーキテクチャ

```
本流 Omoi（GitHub Pages、staticのまま）
  スクリプト/live-room.js     ルーム作成ヘルパー（OmoiLive.startLiveMode など）
                              DEFAULT_ORIGIN は本番URL。localStorage "omoiLiveOrigin" で上書き可
  level-select / warning / warning3 / custom-confirm にチェックボックスと遷移を実装

omoi-live/（Cloudflare Workers、別デプロイ）
  src/index.js   /api/rooms (CORS: *)、/api/rooms/:code/ws → RoomDO へ転送
                 /r/:code と /host/:code は room.html を返す
  src/room.js    RoomDO: WebSocket Hibernation + storage(JSON 1キー) + alarm(3時間で削除)
  public/        room.html / room.js（ホスト・参加者共通UI）/ index.html（コード入力）/ style.css / qrcode.js(MIT, Kazuhiko Arase)
```

## 実装上のハマりどころ（再発防止メモ）

1. **`acceptWebSocket` の第2引数はタグ（文字列配列）**。attachment は `ws.serializeAttachment()` で渡す
2. **Workers Assets は既定で `/room.html` → `/room` に307リダイレクト**する。`wrangler.jsonc` で `"html_handling": "none"` にし、`/` は Worker から `/index.html` へ手動振り替え
3. **WebSocket を DO へ転送するとき URL を書き換えない**（`stub.fetch(request)` 素通し。DO側でパスの後方一致で受ける）
4. **`alarm()` ハンドラがクラスにないと setAlarm が例外**になる
5. 自動公開の条件に「2人以上」を入れた経緯: 1人のまま回答すると即公開され、後から入った人が書けなくなるため
6. 正規表現の捕獲グループ番号ミスで `hostMatch[2]`（undefined）を参照していたバグがあった。`/host/:code` の code は `[1]`
7. DOへの `fetch` で URL を `new Request(url, request)` で作り直すと WebSocket アップグレードが壊れる

## テストの実行方法

```sh
# ローカルでDO結合テスト（Node.js >= 22、wrangler dev を先に起動）
cd omoi-live && npx wrangler dev --port 8787
BASE=http://localhost:8787 node omoi-live/flow-test.mjs

# 本流のe2e（ルームサーバーはモック。実機不要）
npx playwright test e2e/live-mode.spec.js --reporter=line --timeout=60000

# 本流のリグレッション
npx playwright test e2e/home.spec.js e2e/pickup.spec.js e2e/v3-normal-flow.spec.js e2e/display-settings.spec.js --reporter=line --timeout=120000
```

本流からローカルのルームサーバーを使うときは、ブラウザコンソールで
`localStorage.setItem("omoiLiveOrigin", "http://localhost:8787")`。

## 残タスク・改善候補

1. **実機確認**: iPhone実機＋Macブラウザで家族・友達の人数分の同時利用を試す（jitterやリロード耐性）
2. **途中参加の救済**: 公開済みの問いに途中参加した人はその問いを書けない（公開ビューを見るだけ）。遅れて書ける「遅筆フォロー」は v2 候補
3. **問い数上限の表示**: 100問を超える選択では切れることを画面で告知する
4. **ふりがな**: ルームUIはふりがな未対応（若い参加者がいる場合の検討）
5. **DNS移行**（任意）: `live.omoi.viuk-light.org` を使うなら、Xdomain管理のDNSをCloudflareへ移行してから Workers Custom Domain を追加（メールMXなし、レコード少なので低リスク）。現状 workers.dev のままで運用可
6. ** abuse 対策**: コード総当たりでの入室や連投のレート制限は未実装（揮発で影響小だが、公開範囲を広げるなら検討）
7. main ブランチへの取り込みは、Beta での試用評価の後に判断
