https://omoi.viuk-light.org

社会や価値観について話すための、オープンソースの質問カードです。

Omoiは、同じ考えになるためのものではありません。
**違う考えを知るために。**

## 使い方

1. Level 1〜4から、話す深さを選びます。
2. 表示された質問について話します。
3. Level 3・4では、必要なら「この問いを知る」から背景や異なる考え方を確認できます。Level 1・2には背景解説はありません。
4. 話したくない質問は「今回は話さない」で飛ばせます。飛ばした分は別の質問に置き換わらず、選んだ枚数に含まれます。

正解を決める必要はありません。
「なぜそう思う？」まで話してみてください。

**考えが変わらなくてもいい。**

## Levels

| Level | 名前 | 内容 |
| --- | --- | --- |
| 1 | 身近な話 | 日常や身近な価値観について |
| 2 | 考える話 | 少し意見が分かれる話について |
| 3 | 重い話 | 社会や倫理について |
| 4 | 深い話 | 自分に置き換えて考える、非常に重く深い話 |

Level 4では、家族、信頼、仕事、人生など、自分自身に置き換えると強く価値観が表れるテーマも扱います。中高生の妊娠・性などを一人称で置くカードも含みます。

Level 4の前には警告画面があります。Omoiは対話のきっかけであり、相談窓口や緊急支援ではありません。カード単位の相談先表示はありません。話したくない・苦しい質問は飛ばすか、セッションを終えてください。

## 「この問いを知る」

背景解説があるのは、現在 Level 3 と Level 4 の質問です。Level 1 と Level 2 にはありません。

解説は答えを決めるためのものではありません。異なる立場や論点、不確実な点を知った上で、自分の考えを話すための補助情報です。

ほとんどの解説には出典がまだ付いていません。制度・医療・政策に触れる文も含め、公開時点の補助として読んでください。出典の追加を歓迎します。

## Privacy

Omoiは、会話の内容や回答を入力・保存することを前提にしていません。

- アカウント不要
- 回答の保存なし
- 回答の収集なし
- 広告なし
- 課金なし

質問をきっかけに、目の前の相手と話すことを中心に設計しています。

サイトは GitHub Pages で配信しています。HTTPS の強制はしておらず、HTTP でも開けます。閲覧そのものの通信ログは、ホスティング側に残る場合があります。

## Questions / Data

質問はJSONで管理しています。

```text
level1.json
level2.json
level3.json
level4.json
```

質問には、Level、上位カテゴリ、具体的な論点、センシティブ度、背景解説などのメタデータを持たせています。Levelは対象者ではなく、会話の深さと扱う判断の重さを表します。`sensitivity`は難しさではなく、話す前に配慮が必要な度合いです。`content_warning` は編集用のタグで、アプリ画面にはまだ出していません。

データ項目と編集ルールは [QUESTION_DATA_SCHEMA.md](QUESTION_DATA_SCHEMA.md) を参照してください。

質問文や解説は完成されたものではありません。偏った表現、分かりにくい説明、不正確な情報、出典のない断言などを見つけた場合は、IssueやPull Requestでの改善を歓迎します。

### 質問を報告する

質問画面の「この質問をGitHubで報告」から、その質問専用のIssue Formを開けます。
質問ID、Level、質問文、データファイル、表示元URLは自動入力されます。
GitHub上で内容を確認し、問題の種類と具体的な説明を入力して送信してください。

送信されるIssueは公開されます。会話中の回答、氏名、連絡先などの個人情報は入力しないでください。
この窓口は誤字、分かりにくい表現、偏り・不適切さ、事実関係、解説・出典、重複など、質問固有の問題を報告するためのものです。
アプリの表示や操作の不具合などは、通常のIssueとして報告してください。

## Contributing

Omoiでは、特に次のような貢献を歓迎します。

- 新しい質問の提案
- 質問文の改善
- 背景解説の追加・修正
- 出典の追加
- Level / sensitivity の見直し
- UI / UXの改善
- アクセシビリティ改善
- 翻訳
- バグ修正

質問を追加するときは、片方の答えだけが明らかに正しく見える表現をできるだけ避け、複数の立場から話せる問いにしてください。

## Development

現在は、HTML / CSS / JavaScript とJSONだけで構成しています。

ビルドツールやバックエンドを必要とせず、静的サイトとして動作します。
