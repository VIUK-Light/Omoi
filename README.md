# Omoi

**重い話を、思いをこめて。**

社会や価値観について話すための、オープンソースの質問カードです。

Omoiは、同じ考えになるためのものではありません。
**違う考えを知るために。**

## 使い方

1. Level 1〜4から、話す深さを選びます。
2. 表示された質問について話します。
3. 必要なら「この問いを知る」から背景や異なる考え方を確認します。
4. 話したくない質問は「今回は話さない」で飛ばせます。

正解を決める必要はありません。
「なぜそう思う？」まで話してみてください。

**考えが変わらなくてもいい。**

## Levels

| Level | 名前 | 内容 |
| --- | --- | --- |
| 1 | 身近な話 | 日常や身近な価値観について |
| 2 | 考える話 | 少し意見が分かれる話について |
| 3 | 重い話 | 社会や倫理について |
| 4 | 深い話 | 自分に置き換えて考える、非常に重く深い話 |

Level 4では、家族、信頼、仕事、人生など、自分自身に置き換えると強く価値観が表れるテーマも扱います。

## 「この問いを知る」

一部の質問には、背景を確認するための解説があります。

解説は答えを決めるためのものではありません。異なる立場や論点、不確実な点を知った上で、自分の考えを話すための補助情報です。

## Privacy

Omoiは、会話の内容や回答を入力・保存することを前提にしていません。

- アカウント不要
- 回答の保存なし
- 回答の収集なし
- 広告なし
- 課金なし

質問をきっかけに、目の前の相手と話すことを中心に設計しています。

## Questions / Data

質問はJSONで管理しています。

```text
level1.json
level2.json
level3.json
level4.json
```

質問には、Levelやカテゴリ、必要に応じてセンシティブ度、背景解説などのメタデータを持たせています。

質問文や解説は完成されたものではありません。偏った表現、分かりにくい説明、不正確な情報などを見つけた場合は、IssueやPull Requestでの改善を歓迎します。

## Contributing

Omoiでは、特に次のような貢献を歓迎します。

- 新しい質問の提案
- 質問文の改善
- 背景解説の追加・修正
- 出典の追加
- Level / sensitivity の見直し
- UI / UXの改善
- アクセシビリティ改善
- 翻訳
- バグ修正

質問を追加するときは、片方の答えだけが明らかに正しく見える表現をできるだけ避け、複数の立場から話せる問いにしてください。

## Development

現在は、HTML / CSS / JavaScript とJSONだけで構成しています。

ビルドツールやバックエンドを必要とせず、静的サイトとして動作します。
