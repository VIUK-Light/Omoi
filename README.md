# Omoi v3 プレビュー

**違う考えを知るために。**

重い話題も質問カードをきっかけに話せるようにする、Omoi v3 の試作です。目の前の相手と理由や思いを伝え合うことを中心にしています。会話や回答の入力・保存、広告、課金はありません。

この版は `v3` ブランチで開発しています。[現在の公開版 Omoi](https://omoi.viuk-light.org/) を配信する `main` とは分かれています。新しい v3 コードは独自の非商用ライセンスで提供しており、v3 全体を OSS とは表記しません。

## フォルダー構成

- `画面/選択/`・`画面/対話/`・`画面/データベース/`・`画面/印刷/`・`画面/案内/`: 用途別の画面HTML
- `スクリプト/`: 画面のJavaScript
- `スタイル/`: CSS
- `画像/`: アイコンや共有画像
- `データ/質問/`: 質問本文とふりがなデータ
- `データ/索引/`: 画面表示・検索用に生成する索引データ
- `資料/`: データ仕様、監査記録、レビュー資料
- `tools/`, `e2e/`, `preview/`: 検証ツール、自動テスト、v3プレビュー

GitHub Pagesの入口である `index.html` と、配信設定ファイルはルートに置いています。

## 使い方

1. 「はじめる」から選び方を選びます。
   - **学校・若者向け**：学校や若者に関わる問いからそのまま始まります。
   - **すべてから選ぶ**：次の画面で話の深さ（level:低・中・高）を選び、その中の問いから選びます。
   - **自分で選ぶ**：次の画面で細かいカテゴリーと、個別の問いを組み合わせて選びます（全level横断）。
2. 「すべてから選ぶ」で level:中・高を選ぶと、話し始める前の案内を確認します。学校・若者向け／自分で選ぶでは案内を挟まず、選んだ内容から始まります。
3. 場面と問いを読み、互いの考えや理由を話します。
4. 必要なら補助を開きます。話したくない問いは飛ばし、いつでも終了できます。途中で終えた場合は、次に開いたとき、はじめの選び方の画面から続きを再開できます（この端末のみ）。
5. 共有したい時は、共有ボタンから「リンクを共有」か「問いの画像を保存」を選びます。

| 表示 | 内部の level | 内容 |
| --- | --- | --- |
| level:低 | 2 | 少し意見が分かれる話について |
| level:中 | 3 | 社会や倫理についての重い話 |
| level:高 | 4 | 自分に置き換えて考える、非常に重く深い話 |

画面では level:低・中・高 と表示します。内部データとURLでは従来どおり level 2・3・4 を使います。Level 1は廃止し、残る内部 level の番号と質問は変更していません。

「自分で選ぶ」では、約20個の細分類ラベル（学校・家族・仕事・健康など）と個別の問いを選べます。選んだラベルの問いと個別に選んだ問いを合わせたものが、全levelから出題されます。ラベルは `データ/索引/labels.json` に表示名と並び順を定義し、各質問の `labels` にはIDだけを保存します。`student` ラベルは「学校・若者向け」の対象判定に使います。

level は対象年齢ではなく、会話の深さと扱う判断の重さです。Omoi は相談窓口や緊急支援の代わりにはなりません。[利用時の案内](https://viuk-light.org/omoi-safety.html)も確認できます。

## 3つの補助

補助は level:中・高 のうち必要な問いだけに用意します。初期状態では閉じており、内容があるものだけボタンを表示します。同時に開くのは一つです。カード移動・再読み込みでは閉じた状態に戻り、補助を読まずに対話やスキップができます。

- **問いの要点**：複雑な前提や、何を判断する問いなのかを整理します。問いの言い換えだけになる場合は設けません。
- **会話のヒント**：別の見方や、相手の理由を聞いて対話を深める問い返しです。
- **問いの背景**：必要な用語や、出典との対応を確認できた知識を説明します。未確認の外部の事実説明は掲載しません。

**理解を助けるが、結論は誘導しない。考えるための補助であり、考えることの代わりにはならない。**

文章量・項目数は固定しません。原文にない事実、需要、意図、感情を補わず、同じ内容を複数の補助へ重複させません。補助を全部そろえることは品質基準にしません。

質問データは `データ/質問/level2.json`〜`データ/質問/level4.json` の全743問で管理し、要点も任意の `summary` として同じデータへ保存します。[データ項目・編集ルール](資料/QUESTION_DATA_SCHEMA.md)を参照してください。

level:中・高 全663問の採用・省略理由、独立した読み合わせ、確認した文面の指紋は [レビュー記録](資料/v3-content-review.json)に保存します。文面が変わった場合や、未確認の問いがある場合は検証が失敗するため、再確認してから反映します。この記録は文章の中立性を自動で証明するものではありません。

このプレビューでは要点164問、ヒント663問、用語274問、出典付きの背景本文1問を採用しています。件数は掲載目標ではなく、個別の編集判断の結果です。

## 表示と実験

通常の Omoi 画面に要点とダークモードを組み込みます。配色は端末のライト／ダーク設定へ追従します。使い方・注意画面・規約・終了確認も対象です。

各ページ右上の「表示設定」パネルでは、テーマと背景を選べます。テーマは自動・ライト・ダーク・セピア・ナイト・VIUK-Light・VIUK-Light dark、背景は朝焼け・波・森・和紙・夕暮れ・雲・桜・深海・星空・波紋・格子から選べます。背景の濃さ（100%なら背景をそのまま、0%なら単色）も調整でき、設定は端末に保存され、ページ移動後も同じ設定が続きます。

関係図は検証用を含めて廃止しました。要点や文章の区切り方は [検証用ページ](preview/omoi-v3/preview.html)で比較できます。通常画面に実験用の操作や比較フッター、質問IDは表示しません。

## ローカル確認

```sh
python3 tools/serve.py 4173
```

ブラウザで `http://127.0.0.1:4173/` を開きます。クラウド環境のこのアドレスは利用者の端末から直接は開けないため、共有確認には本人限定の非公開プレビューを使います。

```sh
node --test tools/*.test.mjs preview/omoi-v3/*.test.mjs
node tools/generate-question-labels.mjs --check
node tools/verify-question-dataset.mjs --enforce-quality-targets --summary
node tools/verify-v3-review.mjs --summary
node tools/verify-seo.mjs
npm run test:e2e
```

表示・操作の検証だけで対話が分かりやすくなったとは判定しません。試用では、問いの判断対象を説明できるか、相手の理由を聞きやすくなるかを確認します。
